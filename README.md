# Portfólio · Humberto Meireles Anastácio

Site pessoal publicado em https://humbertoanastacio.github.io

- `index.html`: página única. Todo o conteúdo fica no bloco `DATA`, no início do script.
- Texto entre `[colchetes]` no `DATA` é "a preencher": fica oculto no site publicado. Para conferir o que falta, abra https://humbertoanastacio.github.io/?rascunho
- `mackenzie/index.html`: página "O que estou aprendendo na Mackenzie" (https://humbertoanastacio.github.io/mackenzie/). O conteúdo fica no bloco `DATA`; o `status` de cada módulo marca o que está em curso e `aprendi` lista o que você aprendeu em cada par de disciplinas.
- `og.png` e `og-mackenzie.png`: imagens da prévia ao compartilhar os links (LinkedIn, WhatsApp). `icon.png`: ícone na tela inicial do celular.
- `logos/`: cópia dos logotipos (a página usa versões embutidas no próprio HTML).
